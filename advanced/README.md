# Дополнительные компоненты

Папка `advanced` содержит необязательные дополнения для **img2img helper**. Для обычной работы скрипта они не требуются.

```text
advanced\
├── Forge Extras - GFPGAN CodeFormer.7z
├── img2img API forwarding.vbs
└── README.md
```

## GFPGAN и CodeFormer для Forge Neo

Архив `Forge Extras - GFPGAN CodeFormer.7z` возвращает в Forge Neo модули восстановления лиц, удалённые из некоторых сборок:

- **GFPGAN**;
- **CodeFormer**.

Они нужны для соответствующих режимов Forge-схемы `face-restore`.

### Установка

1. Закройте Forge Neo.
2. Сделайте резервную копию папки Forge Neo или заменяемых файлов.
3. Распакуйте архив **в корневую папку Forge Neo**, сохранив структуру каталогов.
4. Убедитесь, что файлы оказались по следующим путям:

```text
Forge Neo\
└── webui\
    ├── modules\
    │   ├── codeformer_model.py
    │   └── gfpgan_model.py
    ├── scripts\
    │   ├── postprocessing_codeformer.py
    │   └── postprocessing_gfpgan.py
    └── models\
        ├── Codeformer\
        └── GFPGAN\
```

5. Снова запустите Forge Neo.

При первом использовании Forge попытается автоматически скачать модели:

```text
webui\models\Codeformer\codeformer-v0.1.0.pth
webui\models\GFPGAN\GFPGANv1.4.pth
```

Для первой загрузки потребуется интернет. Если автоматическое скачивание не сработало, модели можно поместить в указанные папки вручную с теми же именами файлов.

### Использование

В `img2img helper` выберите Forge preset **Face Restore**, затем включите:

- **GFPGAN** и задайте степень его влияния;
- **CodeFormer** и задайте Visibility и Weight;
- либо оба метода одновременно.

При выключенных GFPGAN и CodeFormer схема Face Restore не выполняет восстановление лица.

### Важные замечания

- Файлы архива заменяют или дополняют внутренние модули Forge Neo.
- После обновления Forge Neo эти файлы могут быть перезаписаны — при необходимости установите дополнение повторно.
- Совместимость зависит от внутренней структуры конкретной сборки Forge Neo.
- Если Forge перестал запускаться после установки, восстановите резервные копии заменённых файлов.
- При отсутствии моделей проверьте папки `webui\models\Codeformer` и `webui\models\GFPGAN`, а также консоль Forge.

## Запуск img2img helper по UUID

Файл `img2img API forwarding.vbs` запускает скрипт через зарегистрированный Photoshop event ID:

```text
5f6f57dc-80c8-49b4-9ea9-405d132b7b30
```

Это позволяет назначить запуск на:

- программируемую или POS-клавиатуру;
- макроклавишу;
- системный хоткей;
- Stream Deck и похожие контроллеры;
- внешнюю программу автоматизации.

VBS не ищет JSX-файл по пути. Он обращается к Photoshop по UUID, поэтому `img2img helper.jsx` должен быть установлен в Photoshop и содержать тот же event ID.

### Обычный запуск

Запустите файл двойным щелчком или командой:

```bat
wscript.exe "C:\путь\к\advanced\img2img API forwarding.vbs"
```

Без дополнительных аргументов выполняется обычный вызов скрипта. Показ интерфейса определяется текущим режимом самого `img2img helper`.

### Принудительный запрос интерфейса

При наличии любого аргумента VBS добавляет к вызову параметр `--dialog`:

```bat
wscript.exe "C:\путь\к\advanced\img2img API forwarding.vbs" dialog
```

Для программируемой клавиатуры можно создать две команды:

```text
Без аргумента  → обычный запуск
С аргументом   → запуск с запросом диалогового окна
```

Название переданного аргумента не имеет значения: VBS проверяет только факт его наличия.

### Настройка хоткея или POS-клавиатуры

В программе клавиатуры или менеджере хоткеев укажите:

```text
Программа:
C:\Windows\System32\wscript.exe
```

Обычный запуск:

```text
Аргументы:
"C:\путь\к\advanced\img2img API forwarding.vbs"
```

Запуск с интерфейсом:

```text
Аргументы:
"C:\путь\к\advanced\img2img API forwarding.vbs" dialog
```

Рабочую папку обычно указывать не требуется.

### Возможные проблемы

**Ничего не происходит**

- проверьте, установлен ли `img2img helper.jsx` в Photoshop;
- перезапустите Photoshop после установки JSX;
- убедитесь, что UUID в VBS совпадает с event ID скрипта;
- проверьте, не блокирует ли Windows запуск `.vbs`;
- попробуйте выполнить команду через `wscript.exe` вручную.

**Открывается не тот режим интерфейса**

Проверьте, передаётся ли дополнительный аргумент после пути к VBS. Без него выполняется обычный вызов, с ним передаётся `--dialog`.

**Ошибка не отображается**

В VBS используется `On Error Resume Next`, поэтому ошибки COM-вызова могут завершаться без отдельного окна. Для диагностики сначала запустите `img2img helper` вручную из Photoshop и убедитесь, что сам скрипт работает.
