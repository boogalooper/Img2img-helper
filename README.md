# img2img helper

**img2img helper** отправляет выделенную область из Adobe Photoshop в ComfyUI или Forge Neo и помещает результат обратно в документ отдельным слоем с маской. Поддерживаются img2img, inpainting, референсные изображения и запуск из Photoshop Actions.

Рабочий процесс: **выделить область → выбрать бэкенд и workflow/пресет → настроить параметры → Generate**.

## Возможности

- ComfyUI и Forge Neo, в том числе на другом компьютере в локальной сети;
- несколько workflow и Forge-пресетов с отдельными настройками;
- img2img и inpainting через Quick Mask;
- Reference images, ImageStitch и LoRA;
- библиотеки Prompt и Negative prompt;
- автоматическое и ручное изменение размера;
- восстановление настроек из созданного слоя;
- запись и воспроизведение Photoshop Actions.

## Требования

- Windows;
- Adobe Photoshop 2020 или новее;
- документ Photoshop в режиме RGB;
- Python 3.9 или новее;
- ComfyUI, Forge Neo либо оба бэкенда;
- модели и дополнительные ноды, необходимые выбранному workflow или пресету.

## Установка

Скопируйте файлы в каталог скриптов Photoshop:

```text
Photoshop\Presets\Scripts\
├── img2img helper.jsx
├── img2img-api.pyw
└── forge-schemas\
    └── ...
```

`img2img-api.pyw` и `forge-schemas` также можно разместить в подпапке `lib`.

1. Установите Python 3.9 или новее.
2. Подготовьте ComfyUI или Forge Neo по инструкции ниже.
3. Скопируйте файлы и перезапустите Photoshop.
4. Запустите нужный бэкенд.
5. Откройте **File → Scripts → img2img helper**.

При первом запуске скрипт установит недостающие компоненты. Интернет требуется только для их установки и перевода промптов; локальная генерация работает без него.

### Подготовка ComfyUI

1. В настройках ComfyUI включите **Enable Dev mode Options**.
2. Откройте нужный workflow.
3. Выберите **File → Export Workflow (API)**.
4. Сохраните JSON в папку, указанную в настройках `img2img helper`.

Обычный JSON, созданный через **File → Save**, не подходит: скрипту нужен API-формат.

### Подготовка Forge Neo

Forge Neo должен быть запущен с параметром `--api`. Для стандартной установки Windows добавьте его в `webui-user.bat`:

```bat
set COMMANDLINE_ARGS=--api
```

Если параметры уже указаны, допишите `--api` через пробел. При запуске через менеджер добавьте параметр в его настройки.

## Быстрый старт

1. Откройте RGB-документ и выделите область для обработки.
2. Запустите `img2img helper`.
3. При первом использовании откройте общие настройки кнопкой `⚙` и укажите папку с API-workflow или `forge-schemas`.
4. Выберите **Backend** и workflow/пресет.
5. Настройте Prompt и остальные параметры.
6. Нажмите **Generate**.

Результат появится на слое `generated image` с маской исходного выделения. Если бэкенд вернул несколько изображений, используется первое.

Чтобы принудительно открыть интерфейс только для текущего запуска, удерживайте Shift при запуске скрипта.

## ComfyUI

### Workflow

Скрипт работает с API-workflow из выбранной папки. После изменения схемы экспортируйте её заново и замените JSON-файл.

При первой загрузке анализатор проверяет входные изображения, маски, выходы и управление размером, выбирая подходящие варианты автоматически. Настройки можно проверить или изменить кнопкой `⚙` рядом со списком workflow.

Для входов `LoadImage` доступны роли:

- **Изображение Photoshop** — текущее выделение;
- **Референс** — файл, выбранный в интерфейсе скрипта;
- **Файл из workflow** — файл, сохранённый в API-workflow;
- **Пустое изображение** — нейтральное изображение подходящего размера.

Если для референса выбрано `None`, сохранённый в ноде файл не используется. Перед экспортом workflow проверьте `LoadImage`, которые должны постоянно брать файл из JSON.

При нескольких выходных нодах скрипт автоматически предпочитает подходящую терминальную `SaveImage` и сообщает о выборе. Выход всегда можно назначить вручную. Если выбранная нода не вернула изображение, скрипт предложит проверить настройки workflow.

### Управление размером

- **Автоматически** — безопасно изменяет найденные поля Width/Height; если это невозможно, используется размер входного изображения.
- **Размер входного изображения** — не изменяет поля workflow.
- **Выбранные поля Width/Height** — записывает размер в указанную пользователем пару полей.

Для каждого workflow можно задать формат результата, кратность размера и набор параметров, отображаемых в главном окне.

### Inpainting

1. Перейдите в режим **Quick Mask** и создайте маску изменяемой области.
2. Не выходя из Quick Mask, создайте внешнее выделение, задающее границы отправляемого фрагмента.
3. Запустите генерацию.

В настройках workflow выбранная маска должна иметь статус **используется в workflow**.

## Forge Neo

Forge Neo использует JSON-пресеты из папки `forge-schemas`. Доступные модели, параметры, Face Restore и Upscaler зависят от установленного Forge Neo и выбранного пресета.

LoRA выбираются в отдельном диалоге и сохраняются для текущего пресета. В пресет промпта записывается только текст.

Пресеты с ImageStitch поддерживают до трёх дополнительных файлов форматов JPG, PNG и WebP. Недоступные и повторяющиеся файлы пропускаются; если подходящих изображений нет, генерация продолжается без ImageStitch.

## Промпты и профили

Prompt и Negative prompt имеют отдельные библиотеки. Доступны создание, обновление, удаление и восстановление сохранённого текста. Последний выбранный вариант запоминается отдельно для каждого workflow или Forge-пресета.

Кнопка перевода переводит текущий промпт на английский и требует подключения к интернету. Недоступность перевода не влияет на генерацию.

Настройки моделей, параметров генерации, размера, референсов и LoRA также сохраняются отдельно для каждого workflow/пресета.

## Размер и размещение результата

**Auto resize** рассчитывает масштаб для каждого выделения по выбранному профилю. Ручное изменение ползунка отключает автоматический режим и сохраняет масштаб для текущего workflow/пресета.

Кратность размера задаётся отдельно для каждого профиля. Скрипт уменьшает область до ближайшего допустимого размера, не выходя за границы исходного выделения.

Параметр **Объединять слои перед генерацией** отправляет итог всех видимых слоёв, не изменяя структуру документа. Способ размещения результата и сохранение пропорций задаются в общих настройках.

## Управление workflow и пресетами

| Кнопка | Действие |
|---|---|
| `↻` | обновить список или выбранный элемент |
| `⟳` | повторно проверить или полностью сбросить настройки |
| `✔` | сохранить настроенную копию через Save As |
| `⚙` | открыть настройки выбранного элемента |

Обычное обновление сохраняет пользовательские значения. Полный сброс удаляет настройки только выбранного workflow или пресета.

## Метаданные и Photoshop Actions

При сохранении метаданных слой `generated image` хранит параметры генерации. Кнопка **LOAD** восстанавливает бэкенд, workflow/пресет, промпты, размер, референсы, LoRA и другие настройки профиля.

Параметр **Record settings to action** управляет Photoshop Actions:

- выключен — Action использует текущие настройки скрипта;
- включён — Action использует снимок параметров, сохранённый при записи.

Показ интерфейса настраивается стандартным переключателем диалога у шага Action. Если записанный бэкенд, workflow или пресет недоступен, выполнение завершается с ошибкой без автоматической подмены.

Отмена через прогресс-бар считается штатным завершением: документ восстанавливается, сообщение об ошибке не показывается.

## Работа по локальной сети

В общих настройках укажите адрес компьютера с ComfyUI или Forge Neo и соответствующий порт. Остальной порядок работы не меняется.

## Устранение проблем

| Проблема | Что проверить |
|---|---|
| Workflow отсутствует в списке | Папку, API-формат JSON и обновление списка |
| Workflow работает неверно | Роли входов, маску, выход и управление размером в настройках `⚙` |
| Используется старый файл | Роль **Файл из workflow** и содержимое `LoadImage` в экспортированном JSON |
| Не работает inpainting | Quick Mask, внешнее выделение и подключение выбранной маски |
| Бэкенд не обнаружен | Запуск, адрес, порт и параметр `--api` для Forge Neo |
| Не запускается Action | Доступность записанного бэкенда, workflow/пресета, моделей и параметров |
| Не запускается Python | Установку Python и расположение `img2img-api.pyw` рядом с JSX или в `lib` |

Если workflow был существенно изменён, выполните повторный анализ или полный сброс его профиля.

## Ограничения

- поддерживается только Windows;
- документ Photoshop должен быть в режиме RGB;
- Automatic1111 и старые версии Forge официально не поддерживаются;
- модели, LoRA и дополнительные ноды устанавливаются отдельно;
- из нескольких результатов в Photoshop помещается первое изображение.
