# img2img helper

**img2img helper** — скрипт для Adobe Photoshop, который передаёт выделенную область в **ComfyUI** или **Forge Neo**, получает результат генерации и размещает его в документе отдельным слоем с маской.

Скрипт предназначен для работы в режиме **img2img непосредственно из Photoshop**: пользователь выбирает область изображения, настраивает параметры генерации и получает результат без ручного экспорта и последующего импорта файлов.

## Возможности

- генерация через ComfyUI и Forge Neo;
- работа с несколькими ComfyUI API-workflow и Forge-пресетами;
- inpainting через режим Quick Mask в ComfyUI;
- поддержка референсных изображений;
- библиотеки Prompt и Negative prompt;
- поддержка LoRA;
- автоматическое и ручное масштабирование;
- Face Restore и Upscaler через Forge Neo;
- сохранение параметров в Photoshop Actions;
- восстановление настроек из метаданных созданного слоя;
- автоматический запуск локального Python API и установка недостающих компонентов;
- диалоговый и тихий запуск из Photoshop Actions.

## Требования

- Windows;
- Adobe Photoshop 2020 (или новее); совместимость с более ранними версиями не проверялась;
- документ Photoshop в режиме RGB;
- Python 3.9 или новее;
- запущенный ComfyUI, Forge Neo либо оба бэкенда;
- установленные модели, VAE, text encoders, LoRA, custom nodes и расширения, используемые выбранным workflow или пресетом.

## Установка

Рекомендуемая структура файлов:

```text
Photoshop\Presets\Scripts\
├── img2img helper.jsx
├── img2img-api.pyw
└── forge-schemas\
    ├── sd.json
    ├── xl.json
    ├── flux.json
    └── ...
```

Файл Python API и каталог `forge-schemas` также можно разместить в подпапке `lib`.

1. Установите Python 3.9 или новее. Во время установки рекомендуется включить параметр **Add Python to PATH**.
2. Подготовьте используемые бэкенды:
   - **ComfyUI** — рекомендуется [Windows Portable или Manual Install](https://github.com/Comfy-Org/ComfyUI). В ComfyUI откройте **Settings → Comfy → Dev Mode** и включите **Enable dev mode options (API save, etc.)**. Это добавляет экспорт workflow в API-формате, необходимом `img2img helper`.
   - **Forge Neo** — в `webui-user.bat` добавьте `--api` в строку `set COMMANDLINE_ARGS=`. Если в ней уже есть параметры, просто добавьте `--api` через пробел.
3. Скопируйте файлы проекта в каталог Photoshop `Presets\Scripts`.
4. Перезапустите Photoshop.
5. Запустите ComfyUI, Forge Neo или оба бэкенда.
6. Откройте скрипт в Photoshop:

```text
File → Scripts → img2img helper
```

При первом запуске скрипт автоматически запускает локальный Python API. Если отсутствуют необходимые Python-компоненты, в окне прогресса появляется сообщение об их установке. 

Интернет-соединение требуется только для первоначальной установки недостающих компонентов и перевода промптов. Обычная локальная генерация через ComfyUI или Forge Neo не требует доступа в интернет.

## Быстрый старт

1. Откройте RGB-документ и выделите область, которую нужно обработать.
2. Запустите `img2img helper`.
3. При первом запуске откройте общие настройки кнопкой `⚙`.
4. Для ComfyUI укажите каталог с экспортированными API-workflow.
5. Для Forge Neo укажите каталог `forge-schemas`, если он не найден автоматически.
6. Выберите бэкенд, workflow или Forge-пресет.
7. Настройте параметры и нажмите **Generate**.

Если доступны оба бэкенда, в главном окне отображается переключатель **Backend**. Если при диалоговом запуске доступен только один бэкенд, он выбирается автоматически. Кнопка обновления рядом со статусом позволяет выполнить немедленную повторную проверку.

Результат помещается в документ на слой:

```text
generated image
```

К слою добавляется маска исходного выделения. Если бэкенд вернул несколько изображений, Photoshop использует только первое.

Для повторной генерации той же области можно выбрать ранее созданный слой `generated image`. Если активный слой имеет это имя, скрипт пытается восстановить область по его прозрачности.

## Работа с ComfyUI

### Подготовка API-workflow

`img2img helper` использует только workflow, экспортированные командой:

```text
Export Workflow (API)
```

После изменения исходного workflow экспортируйте его заново и замените соответствующий API-файл в каталоге, указанном в настройках скрипта.

Результат анализа и ручные привязки сохраняются и используются при следующих запусках. Перезапуск Photoshop или Python API не требует повторной настройки workflow. Новый анализ обычно нужен только после изменения API-файла или обновления custom nodes.

При анализе workflow скрипт пытается автоматически определить:

- входное изображение;
- вход inpaint-маски;
- референсные входы;
- выходное изображение;
- поля ширины и высоты;
- основной sampler;
- параметры, которые следует показать в Photoshop.

Результат автоматического анализа можно скорректировать в настройках выбранного workflow.

### Настройка workflow

Кнопка `⚙` рядом со списком workflow открывает его настройки. В этом окне можно:

- назначить входное и выходное изображение;
- указать вход маски;
- настроить референсные входы;
- определить, как поступать с дополнительными невыбранными `LoadImage`;
- выбрать способ управления размером;
- выбрать формат результата JPG или PNG;
- определить набор параметров главного окна;
- задать кратность размера.

Параметры, которые не требуются при каждом запуске, можно скрыть.

### Несколько LoadImage в одном workflow

Если workflow содержит несколько нод `LoadImage`, при анализе скрипт предлагает проверить их назначение. Если основной вход определить однозначно нельзя, откройте настройки workflow и явно выберите **Input image** и нужные **Reference inputs**.

Параметр **Ignore unselected LoadImage nodes** определяет поведение остальных обычных `LoadImage`:

- **выключен** — невыбранные ноды остаются с теми значениями, которые записаны в самом workflow;
- **включён** — невыбранные ноды получают нейтральное пустое изображение.

Повторное предупреждение перед каждой генерацией не показывается. Если в самом workflow остался недоступный путь или другая проблема, сообщение вернёт сам ComfyUI.

Если обычная нода `LoadImage` выбрана как **Reference input**, но для неё в главном окне оставлено `None`, скрипт молча использует нейтральное пустое изображение. Нестандартные загрузчики изображений автоматически не заменяются.

### Поиск непонятного поля или одноимённой ноды

Для неоднозначных параметров скрипт показывает тип и внутренний идентификатор:

```text
CFG — PrimitiveFloat [node_170:154__value]
Steps — PrimitiveInt [node_170:165__value]
Enable 4steps LoRA? — PrimitiveBoolean [node_170:168__value]
```

Чтобы найти соответствующую ноду в ComfyUI:

1. Загрузите **тот же экспортированный API-файл, который подключён к `img2img helper`**. Не используйте для поиска исходный workflow: его идентификаторы могут отличаться.
2. Откройте **Settings** (`Ctrl + ,`).
3. Перейдите в раздел **LiteGraph (Canvas)**.
4. Для параметра **Node ID badge mode** выберите **Show all**.
5. Сопоставьте ID на ноде с идентификатором в квадратных скобках.

Обычный идентификатор:

```text
node_42__cfg
     │    └─ имя входа
     └────── ID ноды
```

Для ноды внутри subgraph используется составной ID:

```text
node_170:168__value
```

Если несколько параметров имеют одинаковое название, ориентируйтесь на полный ID в квадратных скобках.

### Метки нод

В сложных workflow можно добавить служебные метки в заголовки нод:

| Метка | Назначение |
|---|---|
| `#PS-INPUT` | основной вход изображения из Photoshop |
| `#PS-OUTPUT` | изображение, возвращаемое в Photoshop |
| `#PS-SIZE` | основные поля ширины и высоты |
| `#PS-MAIN` | основной sampler |
| `#PS-REF` | референсный вход |
| `#PS-MASK` | вход inpaint-маски |
| `#PS-UI` | параметры ноды, предлагаемые для интерфейса |

После изменения меток повторно экспортируйте workflow в API format.

### Управление размером

Для ComfyUI доступны три режима:

- **Автоматически** — используются однозначно найденные поля ширины и высоты;
- **Размер входного изображения** — поля размера в workflow не изменяются;
- **Выбранные поля width/height** — нужная пара назначается вручную.

Для workflow, использующих `GetImageSize` или аналогичную логику, обычно подходит режим **Размер входного изображения**.

После изменения структуры workflow, custom nodes или списка допустимых значений выполните повторный анализ кнопкой `⟳`.

### Quick Mask inpainting

Для inpainting перейдите в режим Quick Mask и создайте маску. Не выходя из Quick Mask, создайте выделение, обозначив границы отправляемой области.

При генерации:

- внешнее выделение определяет размер отправляемой области;
- Quick Mask определяет пиксели, которые разрешено изменить.

## Работа с Forge Neo

Forge Neo использует JSON-схемы из каталога `forge-schemas`. Каждая схема определяет доступные параметры и их исходные значения.

Поставляемый набор может включать пресеты для:

- SD и SDXL;
- FLUX;
- KLEIN;
- QWEN;
- KREA 2;
- Lumina;
- Anima;
- Ernie;
- Z-Image;
- Face Restore;
- Upscaler.

Набор элементов в главном окне зависит от выбранного пресета.

### LoRA

Доступные LoRA выбираются в отдельном окне и автоматически добавляются к запросу. Вводить служебные теги вручную не требуется.

При сохранении пресета Prompt в него записывается только текст. Выбранные LoRA хранятся отдельно.

### ImageStitch

В поддерживаемых схемах ImageStitch позволяет использовать до трёх внешних изображений.

Поддерживаемые форматы:

```text
jpg, jpeg, png, webp
```

Отсутствующие, повторяющиеся и неподдерживаемые файлы пропускаются. Если подходящих изображений не осталось, генерация продолжается без ImageStitch.

История недавно выбранных файлов общая для ComfyUI и Forge Neo.

### Face Restore и Upscaler

Пресет **Face Restore** поддерживает GFPGAN, CodeFormer или их совместное использование, если соответствующие методы доступны в Forge Neo. Для запуска необходимо включить хотя бы один метод.

Пресет **Upscaler** позволяет выбрать коэффициент масштабирования, основной upscaler и при необходимости дополнительный upscaler.

## Промпты и пресеты

Для Prompt и Negative prompt используются отдельные библиотеки пресетов.

| Кнопка | Действие |
|---|---|
| `↻` | восстановить текст выбранного пресета; для пресета по умолчанию поле очищается |
| `+` | создать пресет из текущего текста |
| `✔` | обновить выбранный пресет |
| `×` | удалить выбранный пресет |

Пресет по умолчанию нельзя удалить или перезаписать.

Кнопка перевода преобразует текст промпта в английский язык. Для перевода требуется интернет-соединение.

В Forge Neo, если обычный **CFG Scale** установлен в `1` или ниже, поле Negative prompt автоматически отключается и его содержимое не передаётся Forge.

## Размер и размещение результата

### Auto resize

Автоматический размер рассчитывается по исходному выделению и выбранному resize-профилю. Профиль задаёт минимальную сторону и максимально допустимое количество мегапикселей.

Можно использовать встроенные профили или создавать собственные. Пока **Auto resize** включён, коэффициент пересчитывается автоматически для текущей области при каждом запуске.

Если при включённом **Auto resize** вручную сдвинуть ползунок масштаба, автоматический режим сразу отключается. Выбранное значение становится постоянным ручным масштабом для этого workflow или Forge-пресета и сохраняется в настройках, метаданных и Photoshop Action, если для Action включена запись параметров.

Чтобы снова использовать автоматический расчёт, включите **Auto resize** — значение будет пересчитано по текущему выделению и выбранному resize-профилю.

### Ручной режим

Если **Auto resize** выключен, коэффициент масштабирования задаётся вручную и используется в последующих запусках до следующего изменения или повторного включения автоматического режима.

### Кратность размера

Каждый ComfyUI workflow и Forge-пресет может использовать собственную кратность. Если значение не задано, используется `16`.

Перед генерацией скрипт уменьшает область до ближайшего меньшего размера, кратного выбранному значению. Границы исходного выделения не расширяются.

## Управление workflow и пресетами

Рядом со списком workflow или Forge-пресетов расположены основные команды:

| Кнопка | ComfyUI | Forge Neo |
|---|---|---|
| `↻` | обновить список workflow | обновить выбранную schema и связанные данные |
| `⟳` | повторно проанализировать workflow или выполнить полный сброс | обновить список schema и выбранный профиль или выполнить полный сброс |
| `✔` | сохранить копию workflow с текущими видимыми значениями через **Save As** | сохранить копию schema с текущими видимыми значениями через **Save As** |
| `⚙` | открыть настройки workflow | открыть настройки schema |

При использовании `⟳` можно повторно проанализировать/загрузить выбранный workflow или Forge-пресет с сохранением пользовательских значений либо выполнить полный сброс. Полный сброс удаляет сохранённые значения и индивидуальные настройки только выбранного профиля.

После сохранения через `✔` созданный JSON загружается в скрипт и становится текущим, если он расположен в используемом каталоге workflow/schema.

## Общие настройки

В общих настройках можно изменить:

- адрес компьютера с бэкендом и порты ComfyUI и Forge Neo;
- каталог API-workflow;
- каталог Forge-схем;
- resize-профили;
- способ подготовки видимых слоёв;
- способ размещения результата;
- параметры кисти;
- запись настроек в Photoshop Actions;
- сохранение метаданных слоя;
- таймаут генерации;
- время остановки Python API при отсутствии работы;
- интервал фоновой проверки ComfyUI и Forge Neo.

В разделе **Python-сервер** отображается текущая версия Python API. По умолчанию сервер останавливается после 15 минут бездействия и автоматически запускается снова при следующем обращении к скрипту. Значение `0` отключает автоматическую остановку.

Фоновая проверка позволяет главному окну использовать актуальное состояние ComfyUI и Forge Neo без отдельного ожидания при каждом запуске. Кнопка проверки в настройках выполняет немедленный опрос обоих бэкендов.

## Метаданные и Photoshop Actions

### Метаданные слоя

При включённом сохранении метаданных созданный слой содержит параметры генерации.

Если активный слой содержит совместимые данные, в верхней части окна появляется кнопка **LOAD**. Она восстанавливает:

- использованный бэкенд;
- workflow или Forge-пресет;
- значения параметров;
- настройки размера;
- референсные изображения и LoRA, относящиеся к выбранному профилю.

Эта функция позволяет повторить генерацию или продолжить работу после перезапуска Photoshop.

### Photoshop Actions

Параметр **Записывать настройки в экшен (Record settings to action)** определяет источник настроек при воспроизведении Action.

**Параметр выключен.** Action использует текущие общие настройки: выбранный бэкенд, workflow или Forge-пресет и последние значения пользователя. Изменение общих настроек влияет на последующие запуски такого Action.

**Параметр включён.** Action хранит собственный снимок настроек: выбранный бэкенд, workflow или Forge-пресет, значения профиля, resize и относящиеся к профилю reference/LoRA/ImageStitch-настройки. Такой Action воспроизводится независимо от текущего пользовательского профиля.

Доступность ComfyUI и Forge Neo на момент записи Action не сохраняется. В тихом режиме скрипт всегда использует бэкенд, выбранный в общих настройках или записанный в Action, и **не переключается автоматически на другой бэкенд**. Если этот бэкенд недоступен, шаг завершается с ошибкой.

Библиотеки Prompt/Negative prompt, общая история reference-файлов и каталоги workflow/Forge-схем в Action не дублируются: они берутся из актуальных общих настроек или заново получают данные от бэкенда.

Показ главного окна при воспроизведении управляется стандартным переключателем диалога у шага Photoshop Action. Если показ диалога выключен и сохранённые параметры валидны, Action выполняется в тихом режиме.

## Работа по локальной сети

ComfyUI и Forge Neo могут работать на другом компьютере в локальной сети.

Укажите IP-адрес удалённого компьютера и соответствующий порт в общих настройках. Бэкенд должен принимать внешние подключения, а брандмауэр — разрешать доступ к используемому порту.

Python API `img2img helper` всегда запускается на компьютере с Photoshop.

При подключении к удалённому ComfyUI локальный Python API не может автоматически удалять служебные input/output-файлы на другом компьютере.

## Устранение проблем

### Workflow отсутствует в списке

Проверьте, что выбран правильный каталог и файл экспортирован через **Export Workflow (API)**. Если команды API-экспорта в ComfyUI нет, включите **Settings → Comfy → Dev Mode → Enable dev mode options (API save, etc.)**. После изменения исходного workflow создайте новый API-экспорт, замените старый файл и нажмите `↻`.

### Параметры workflow определены неправильно

Откройте настройки workflow кнопкой `⚙` и вручную назначьте вход, выход, маску, размер и видимые параметры.

Если workflow содержит несколько `LoadImage`, обязательно проверьте **Input image** и **Reference inputs**. При необходимости включите **Ignore unselected LoadImage nodes** для дополнительных входов, которые не должны использовать изображения из самого workflow.

После изменения структуры workflow или custom nodes выполните повторный анализ кнопкой `⟳`.

### Не удаётся определить соответствующую ноду

Загрузите в ComfyUI именно экспортированный API-файл, включите **Node ID badge mode → Show all** и сравните ID ноды с идентификатором в квадратных скобках.

Подробнее см. раздел [Поиск непонятного поля или одноимённой ноды](#поиск-непонятного-поля-или-одноимённой-ноды).

### Бэкенд не обнаружен

Проверьте:

- запущен ли ComfyUI или Forge Neo;
- для Forge Neo добавлен ли параметр `--api` в `webui-user.bat`;
- правильно ли указаны адрес и порт;
- не блокирует ли соединение брандмауэр;
- разрешены ли внешние подключения при работе по сети.

После изменения настроек повторно запустите проверку доступности бэкендов.

### Python API не запускается

Проверьте:

- находится ли `img2img-api.pyw` рядом с JSX или в подпапке `lib`;
- установлен ли Python 3.9 или новее;
- включено ли добавление Python в PATH;
- назначен ли Python приложением для файлов `.pyw`.

Если выполняется первоначальная установка компонентов, дождитесь её завершения. При ошибке скрипт выводит сообщение о причине запуска; дополнительные сведения записываются в журнал.

### Ошибка запуска или генерации

Подробный журнал находится по адресу:

```text
%LOCALAPPDATA%\img2img helper\img2img-api.log
```

При обращении за помощью приложите сообщение об ошибке из Photoshop и соответствующий фрагмент журнала. 

## Ограничения

- поддерживается только Windows;
- скрипт работает только с RGB-документами;
- Automatic1111 и старые версии Forge имеют совместимый API, но официально не поддерживаются;
- модели, VAE, text encoders, LoRA, custom nodes и Forge extensions должны быть установлены заранее;
- из batch-результата в Photoshop помещается только первое изображение.
