# img2img helper

**img2img helper** отправляет выделенную область из Adobe Photoshop в ComfyUI или Forge Neo и помещает результат обратно в документ отдельным слоем с маской. Поддерживаются img2img, inpainting, референсные изображения и запуск из Photoshop Actions или файла параметров.

Рабочий процесс: **выделить область → выбрать бэкенд и workflow/пресет → настроить параметры → Generate**.

## Возможности

- ComfyUI и Forge Neo, в том числе на другом компьютере в локальной сети;
- несколько workflow и Forge-пресетов с отдельными настройками;
- img2img и inpainting через Quick Mask;
- Reference images, ImageStitch и LoRA;
- библиотеки Prompt и Negative prompt;
- автоматическое и ручное изменение размера;
- восстановление настроек из созданного слоя;
- запись и воспроизведение Photoshop Actions;
- сохранение параметров в DESC-файл и запуск из него без главного окна.

## Требования

- Windows;
- Adobe Photoshop 2020 или новее;
- документ Photoshop в режиме RGB;
- Python устанавливается автоматически; для работы без установщика — системный Python 3.10 или новее;
- ComfyUI, Forge Neo либо оба бэкенда;
- модели и дополнительные ноды, необходимые выбранному workflow или пресету.

## Установка

1. Распакуйте архив и запустите `install_runtime.bat` (Windows 10/11 x64). Выберите обычный режим подключения или режим совместимости с Kaspersky, если он нужен. Python и необходимые компоненты установятся автоматически.
2. Скопируйте **содержимое папки `Photoshop-files`** в каталог Photoshop `Presets\Scripts`, сохранив подпапку `lib` целиком, и перезапустите Photoshop.
3. Подготовьте ComfyUI или Forge Neo по инструкции ниже и запустите нужный бэкенд.
4. Откройте **File → Scripts → img2img helper**.

Структура файлов после копирования:

```text
Photoshop\Presets\Scripts\
├── img2img helper.jsx
└── lib\
    ├── img2img-api.pyw
    └── forge-schemas\
        └── ...
```

Файлы можно оставить и в другой постоянной папке, запуская JSX через **File → Scripts → Browse…**.

Общее Python-окружение находится в `%LOCALAPPDATA%\JazzyScripts\SharedRuntime` и может использоваться другими скриптами JazzyScripts. Установщик проверяет уже готовое окружение и создаёт в нём общий `launcher.vbs`. Копировать VBS в папку Photoshop не нужно. ComfyUI, Forge Neo и их модели устанавливаются отдельно.

**Без установщика:** если общего окружения нет, используется системный Python 3.10 или новее. Файлы `.pyw` должны быть связаны с Python. Встроенная установка недостающих компонентов сохранена.

При обновлении используйте JSX и Python-сервер из одного комплекта и обновляйте папку `forge-schemas`. Прежняя структура с `img2img-api.pyw` и `forge-schemas` рядом с JSX также поддерживается. Python-сервер запускается автоматически; совместимую устаревшую сборку скрипт перезапускает сам.

Для первой установки нужен интернет. После подготовки всех компонентов локальная генерация работает без него; для перевода промптов интернет необходим.

### Подготовка ComfyUI

1. В настройках ComfyUI включите **Enable Dev mode Options**.
2. Откройте нужный workflow.
3. Выберите **File → Export Workflow (API)**.
4. Сохраните JSON в папку, указанную в настройках `img2img helper`.

Обычный JSON, созданный через **File → Save**, не подходит: скрипту нужен API-формат.

### Подготовка Forge Neo

Forge Neo должен быть запущен с параметром `--api`. Для стандартной установки Windows добавьте его в `webui-user.bat`:

```bat
set COMMANDLINE_ARGS=--api
```

Если параметры уже указаны, допишите `--api` через пробел. При запуске через менеджер добавьте параметр в его настройки.

## Быстрый старт

1. Откройте RGB-документ и выделите область для обработки.
2. Запустите `img2img helper`.
3. При первом использовании откройте общие настройки кнопкой `⚙` и укажите папку с API-workflow или `forge-schemas`.
4. Выберите **Backend** и workflow/пресет.
5. Настройте Prompt и остальные параметры.
6. Нажмите **Generate**.

Результат появится на слое `generated image` с маской исходного выделения. Если бэкенд вернул несколько изображений, используется первое.

После успешной генерации обычный запуск может сразу повторить обработку с текущими параметрами. Чтобы открыть главное окно, удерживайте **Shift без Ctrl, Alt и Cmd** при запуске скрипта. Для экшенов и запуска из DESC-файла действуют отдельные правила, описанные ниже.

## ComfyUI

### Workflow

Скрипт работает с API-workflow из выбранной папки. После изменения схемы экспортируйте её заново и замените JSON-файл.

При первой загрузке анализатор проверяет входные изображения, маски, выходы и управление размером, выбирая подходящие варианты автоматически. Настройки можно проверить или изменить кнопкой `⚙` рядом со списком workflow.

Для входов `LoadImage` доступны роли:

- **Изображение Photoshop** — текущее выделение;
- **Референс** — файл, выбранный в интерфейсе скрипта;
- **Файл из workflow** — файл, сохранённый в API-workflow;
- **Пустое изображение** — нейтральное изображение подходящего размера.

Если для референса выбрано `None`, сохранённый в ноде файл не используется. Перед экспортом workflow проверьте `LoadImage`, которые должны постоянно брать файл из JSON.

При нескольких выходных нодах скрипт автоматически предпочитает подходящую терминальную `SaveImage` и сообщает о выборе. Выход всегда можно назначить вручную. Если выбранная нода не вернула изображение, скрипт предложит проверить настройки workflow.

После успешной вставки результата скрипт запрашивает очистку своих временных файлов ComfyUI.

### Управление размером

- **Автоматически** — безопасно изменяет найденные поля Width/Height; если это невозможно, используется размер входного изображения.
- **Размер входного изображения** — не изменяет поля workflow.
- **Выбранные поля Width/Height** — записывает размер в указанную пользователем пару полей.

Для каждого workflow можно задать формат результата, кратность размера и набор параметров, отображаемых в главном окне.

### Inpainting

1. Перейдите в режим **Quick Mask** и создайте маску изменяемой области.
2. Не выходя из Quick Mask, создайте внешнее выделение, задающее границы отправляемого фрагмента.
3. Запустите генерацию.

В настройках workflow выбранная маска должна иметь статус **используется в workflow**.

## Forge Neo

Forge Neo использует JSON-пресеты из папки `forge-schemas`. Доступные модели, параметры, Face Restore и Upscaler зависят от установленного Forge Neo и выбранного пресета.

LoRA выбираются в отдельном диалоге и сохраняются для текущего пресета. В пресет промпта записывается только текст.

Для **Qwen-Image 2.1 + Viggle Turbo LoRA** установите расширение [qwen2.1-forge-neo](https://github.com/eduardoabreu81/qwen2.1-forge-neo). Оно добавляет расписание **Viggle Turbo**; обычные Qwen-Image 2.1 и LoRA текущий Forge Neo поддерживает нативно. Пресет `QWEN 2.1 · Viggle 6-step` сам использует `Automatic (fp16 LoRA)` и проверяет наличие расписания Viggle Turbo перед генерацией.

Пресеты с ImageStitch поддерживают до трёх дополнительных файлов форматов JPG, PNG и WebP. Недоступные и повторяющиеся файлы пропускаются; если подходящих изображений нет, генерация продолжается без ImageStitch.

## Промпты и профили

Prompt и Negative prompt имеют отдельные библиотеки. Доступны создание, обновление, удаление и восстановление сохранённого текста. Последний выбранный вариант запоминается отдельно для каждого workflow или Forge-пресета.

Кнопка перевода переводит текущий промпт на английский и требует подключения к интернету. Недоступность перевода не влияет на генерацию.

Настройки моделей, параметров генерации, размера, референсов и LoRA также сохраняются отдельно для каждого workflow/пресета.

## Размер и размещение результата

**Auto resize** рассчитывает масштаб для каждого выделения по выбранному профилю. Ручное изменение ползунка отключает автоматический режим и сохраняет масштаб для текущего workflow/пресета.

Кратность размера задаётся отдельно для каждого профиля. Внутри холста скрипт уменьшает область до ближайшего допустимого размера. Если область касается края холста и её размер не соответствует кратности, при экспорте добавляется временное поле: исходная область у края сохраняется, а результат размещается с учётом этого поля. Размер самого документа после обработки не меняется.

Параметр **Объединять слои перед генерацией** отправляет итог всех видимых слоёв, не изменяя структуру документа. Растеризация результата, сохранение пропорций и выбор кисти после обработки задаются в окне настроек.

## Управление workflow и пресетами

| Кнопка | Действие |
|---|---|
| `↻` | обновить список или выбранный элемент |
| `⟳` | повторно проверить или полностью сбросить настройки |
| `✔` | сохранить настроенную копию через Save As |
| `⚙` | открыть настройки выбранного элемента |

Обычное обновление сохраняет пользовательские значения. Полный сброс удаляет настройки только выбранного workflow или пресета.

## Настройки скрипта

В блоке **Global settings** находятся адрес и порты бэкендов, папки workflow и Forge-схем, таймаут генерации и параметры Python-сервера. Можно настроить остановку сервера после простоя (`0` — не останавливать) и период фоновой проверки бэкендов.

Адреса, порты, папки, таймауты и настройка записи метаданных всегда берутся из текущих настроек этого компьютера, в том числе при запуске экшена или DESC-файла. Библиотеки промптов и история референсов также остаются общими.

Параметры изображения, пресеты Auto resize и настройки кисти входят в сохраняемый снимок вместе с параметрами генерации. Это позволяет повторять обработку, сохраняя местные настройки подключения.

## Метаданные и Photoshop Actions

При сохранении метаданных слой `generated image` хранит параметры генерации. Кнопка **LOAD** восстанавливает бэкенд, workflow/пресет, промпты, размер, референсы, LoRA и другие настройки профиля.

Параметр **Record settings to action** управляет Photoshop Actions:

- выключен — Action использует текущие настройки скрипта;
- включён — Action использует снимок параметров, сохранённый при записи.

Показ интерфейса настраивается стандартным переключателем диалога у шага Action. Shift и режим предыдущего обычного запуска не открывают главное окно у тихого экшена. Если записанный бэкенд, workflow или пресет недоступен, выполнение завершается с ошибкой без автоматической подмены.

Для отмены генерации нажмите **Esc** в окне прогресса и дождитесь завершения отмены. Скрипт отправит команду остановки в ComfyUI или Forge Neo и дождётся освобождения задания в Python. После этого можно запускать следующую генерацию. Если результат ещё не вставлен, документ возвращается к исходному состоянию. При успешной отмене сообщение об ошибке не появляется; если отмену подтвердить не удалось, скрипт сообщит об этом.

## Файлы параметров DESC

Чтобы сохранить текущую настройку обработки, удерживайте **Shift при нажатии Generate** и выберите имя `.desc`-файла. Генерация при этом не запускается, главное окно остаётся открытым. Файл содержит снимок параметров независимо от переключателя **Record settings to action**.

Для выполнения передайте скрипту путь к этому файлу в качестве аргумента вместо флага `dialog`. Главное окно не открывается, даже при зажатом Shift или переданном флаге диалога. При ошибке выполнение прерывается с передачей ошибки Photoshop, как у тихого экшена.

DESC хранит параметры, а не сами workflow, модели и референсные изображения. На другом компьютере должны быть доступны соответствующие схемы и файлы; подключение и папки используются из его глобальных настроек. Экспортированный снимок не заменяет текущие профили скрипта.

## Работа по локальной сети

В **Global settings** укажите адрес компьютера с ComfyUI или Forge Neo и соответствующий порт. Бэкенд должен принимать подключения по локальной сети, а его порт — быть доступен с компьютера Photoshop. Python-сервер скрипта остаётся на компьютере с Photoshop.

Если бэкенд не обнаружен при обычном запуске, нажмите **Открыть настройки** прямо в окне ошибки. Укажите адрес и порт, сохраните изменения и повторите запуск. Кнопка появляется только для ошибок недоступности бэкенда.

## Устранение проблем

| Проблема | Что проверить |
|---|---|
| Workflow отсутствует в списке | Папку, API-формат JSON и обновление списка |
| Workflow работает неверно | Роли входов, маску, выход и управление размером в настройках `⚙` |
| Используется старый файл | Роль **Файл из workflow** и содержимое `LoadImage` в экспортированном JSON |
| Не работает inpainting | Quick Mask, внешнее выделение и подключение выбранной маски |
| Бэкенд не обнаружен | Запуск, адрес, порт и параметр `--api` для Forge Neo |
| Не запускается Action | Доступность записанного бэкенда, workflow/пресета, моделей и параметров |
| Не запускается DESC-файл | Путь к экспортированному файлу, доступность соответствующего workflow/пресета и связанных файлов |
| Не запускается Python | Успешное завершение `install_runtime.bat` и наличие `lib\img2img-api.pyw`; без общего окружения — системный Python и ассоциацию `.pyw` |

Если workflow был существенно изменён, выполните повторный анализ или полный сброс его профиля.

## Ограничения

- поддерживается только Windows;
- документ Photoshop должен быть в режиме RGB;
- Automatic1111 и старые версии Forge официально не поддерживаются;
- модели, LoRA и дополнительные ноды устанавливаются отдельно;
- из нескольких результатов в Photoshop помещается первое изображение.
