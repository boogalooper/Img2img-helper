# img2img helper

**img2img helper** — JSX-скрипт для Adobe Photoshop под Windows, который отправляет выделенную область изображения в **ComfyUI** или **Forge Neo**, получает результат и помещает его обратно в документ на отдельный слой с маской.

Скрипт объединяет в одном интерфейсе:

- работу с несколькими ComfyUI API-workflow;
- генерацию через Forge Neo с готовыми JSON-схемами для разных семейств моделей;
- Quick Mask inpainting в ComfyUI;
- изображения-референсы и ImageStitch в Forge Neo;
- пресеты Prompt и Negative prompt;
- перевод промптов на английский;
- автоматический и ручной resize;
- Face Restore и Upscaler через Forge Neo;
- запись параметров в Photoshop Actions;
- сохранение параметров генерации в метаданных слоя.

Текущая версия JSX и Python API: `0.1`.

## Требования

- Windows.
- Photoshop CC 2014 или новее.
- RGB-документ Photoshop.
- Python 3.9 или новее.
- Хотя бы один запущенный бэкенд:
  - ComfyUI;
  - Forge Neo.
- Для ComfyUI — workflow, экспортированный в API format.
- Все модели, VAE, text encoders, LoRA и custom nodes, используемые выбранным workflow или Forge preset, должны быть установлены заранее.

Доступ в интернет нужен только для перевода промптов и первой автоматической установки Python-пакета `deep-translator`. Основная генерация выполняется локально или в локальной сети.

## Состав проекта

```text
img2img helper.jsx
img2img-api.pyw
forge-schemas/*.json
```

Назначение файлов:

- `img2img helper.jsx` — интерфейс, подготовка изображения и работа с документом Photoshop;
- `img2img-api.pyw` — локальный Python API между Photoshop, ComfyUI и Forge Neo;
- `forge-schemas/*.json` — описание интерфейса и API-запросов Forge Neo.

JSX и Python-файл должны находиться в одной папке, либо Python-файл должен находиться в подпапке `lib` рядом с JSX.

## Установка

### 1. Установите Python

Установите Python 3.9 или новее и включите в установщике Windows:

- `Add Python to PATH`;
- регистрацию файлов `.py` и `.pyw`.

Photoshop запускает `img2img-api.pyw` через системную ассоциацию Windows. Если файл `.pyw` не запускается двойным щелчком, сначала исправьте установку или ассоциацию Python.

### 2. Скопируйте файлы в Photoshop

Скопируйте проект в папку скриптов Photoshop:

```text
C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\
```

Рекомендуемая структура:

```text
Presets\Scripts\
├── img2img helper.jsx
├── img2img-api.pyw
└── forge-schemas\
    ├── sd.json
    ├── xl.json
    ├── flux.json
    └── ...
```

Допустим также вариант с подпапкой `lib`:

```text
Presets\Scripts\
├── img2img helper.jsx
└── lib\
    ├── img2img-api.pyw
    └── forge-schemas\
```

После копирования файлов перезапустите Photoshop.

Скрипт появится в меню:

```text
File → Scripts → img2img helper
```

### 3. Подготовьте бэкенд

Для ComfyUI:

1. Запустите ComfyUI.
2. Дождитесь загрузки custom nodes.
3. Подготовьте папку с workflow, экспортированными через `Export Workflow (API)`.

Для Forge Neo:

1. Запустите Forge Neo.
2. Дождитесь загрузки моделей и API.
3. Разместите папку `forge-schemas` рядом со скриптом либо укажите другой путь в настройках.

## Первый запуск

1. Запустите ComfyUI, Forge Neo или обе оболочки.
2. Откройте RGB-документ Photoshop.
3. Создайте выделение.
4. Запустите `File → Scripts → img2img helper`.
5. При необходимости откройте общие настройки кнопкой `⚙`.
6. Для ComfyUI выберите папку с API-workflow.
7. Для Forge Neo проверьте путь к папке `forge-schemas`.
8. Выберите workflow или Forge preset и нажмите `Generate`.

При первом запуске скрипт автоматически запускает локальный `img2img-api.pyw`, проверяет ComfyUI и Forge Neo и загружает данные активного бэкенда.

Если не найден ни ComfyUI, ни Forge Neo, скрипт показывает ошибку и завершает работу. Окно настроек автоматически не открывается.

Первый анализ ComfyUI workflow может занять несколько секунд, особенно если установлено много custom nodes. Результат анализа кешируется.

## Как пользоваться

Обычный сценарий:

1. Создайте выделение в Photoshop.
2. Запустите `img2img helper` в диалоговом режиме.
3. Выберите `ComfyUI` или `Forge Neo`, если доступны обе оболочки.
4. Выберите workflow или `UI Preset`.
5. Настройте параметры.
6. Нажмите `Generate`.

Photoshop экспортирует выбранную область, Python отправляет её в активный бэкенд, а первое полученное изображение помещается в документ на слой:

```text
generated image
```

Для нового слоя создаётся маска по исходному выделению.

Если обычного выделения нет, но активен ранее созданный слой `img2img helper generated image`, скрипт может использовать его маску или прозрачность как область следующей генерации. Предыдущий результат временно скрывается, поэтому удобно повторять обработку одной и той же области.

В Photoshop возвращается только первое изображение результата. Остальные изображения batch могут сохраниться средствами ComfyUI или Forge Neo, но в документ не вставляются.

## Выбор бэкенда

Скрипт поддерживает два независимых режима:

- `ComfyUI` — работа с пользовательскими API-workflow;
- `Forge Neo` — работа через JSON-схемы из папки `forge-schemas`.

Если доступен только один бэкенд, переключатель в главном окне не показывается. Если доступны оба, появляется список `Backend`.

Скрипт запоминает ранее найденные оболочки и не выполняет полный опрос на каждом запуске. Если ранее доступный бэкенд перестал отвечать, Python проверяет альтернативный.

Чтобы найти оболочку, запущенную уже после старта Python API:

1. Откройте общие настройки.
2. Нажмите `↻` рядом со строкой доступных бэкендов.
3. Сохраните настройки.

Изменение хоста или порта также вызывает новую проверку.

## Подготовка ComfyUI workflow

### Формат файла

Поддерживаются только workflow, сохранённые в API format.

Обычный JSON, сохранённый стандартной кнопкой интерфейса ComfyUI, не подходит. Используйте:

```text
Export Workflow (API)
```

или аналогичную команду:

```text
Save (API Format)
```

Название команды зависит от версии интерфейса ComfyUI.

Создайте отдельную папку для API JSON-файлов. Поддерживаются несколько workflow и вложенные папки.

### Обязательные части

Для обычного img2img нужны:

- вход изображения, обычно `Load Image`;
- цепочка обработки;
- выход изображения, обычно `Save Image` или `Preview Image`.

Скрипт анализирует workflow и пытается автоматически определить:

- основной вход Photoshop;
- вход inpaint-маски;
- изображения-референсы;
- выходную ноду;
- ноду с `width` и `height`;
- основной sampler;
- параметры, которые стоит показать в главном окне.

Результат можно проверить и исправить через кнопку `⚙` рядом со списком workflow.

### Метки нод

Для сложных workflow добавьте метки непосредственно в заголовки нод ComfyUI.

| Метка | Назначение |
|---|---|
| `#PS-INPUT` | Основной вход изображения из Photoshop |
| `#PS-OUTPUT` | Нода, изображение из которой нужно вернуть в Photoshop |
| `#PS-SIZE` | Нода с основными полями `width` и `height` |
| `#PS-MAIN` | Основной sampler или основная нода генерации |
| `#PS-REF` | Вход отдельного изображения-референса |
| `#PS-MASK` | Вход или источник inpaint-маски |
| `#PS-UI` | Показать простые параметры ноды в интерфейсе Photoshop |

Пример названий:

```text
Load Image #PS-INPUT
KSampler #PS-MAIN
Empty Latent Image #PS-SIZE
Load Reference #PS-REF
Load Image Mask #PS-MASK
Save Image #PS-OUTPUT
```

После изменения заголовков нод повторно выполните `Export Workflow (API)` и нажмите `⟳` в Photoshop.

Ручное редактирование ComfyUI JSON для добавления меток не требуется.

### Размер изображения

Если анализатор нашёл поля `width` и `height`, рассчитанный размер записывается в workflow перед отправкой.

Если размерная нода не найдена, Photoshop экспортирует входное изображение уже в нужном размере. Это нормально для workflow, где размер наследуется от `Load Image` через `VAE Encode`.

Если workflow создаёт latent независимо от входного изображения, укажите size-ноду вручную или добавьте к ней `#PS-SIZE`.

### Повторный анализ

Используйте:

- `↻` — перечитать список JSON-файлов;
- `⟳` — удалить кеш выбранного workflow и выполнить полный анализ заново.

Повторный анализ нужен после:

- изменения тегов;
- добавления или удаления нод;
- обновления custom nodes;
- изменения типов входов;
- установки моделей, которых не было при предыдущем анализе;
- появления устаревшего списка параметров.

## Quick Mask inpainting

Inpainting включается автоматически, когда одновременно выполнены два условия:

- Photoshop находится в режиме Quick Mask;
- внутри Quick Mask существует выделение.

Выделение задаёт границы контекста генерации. Содержимое Quick Mask сохраняется и после генерации применяется как маска нового слоя.

В настройках ComfyUI workflow доступно поле `Маска inpaint`.

Поддерживаются два основных варианта:

### MASK основного Load Image

Photoshop сохраняет одно PNG с альфа-каналом. Этот вариант подходит, если workflow использует выход `MASK` основной ноды `Load Image`.

### Отдельная Load Image Mask

Photoshop сохраняет:

- JPEG исходного изображения;
- отдельный чёрно-белый PNG маски.

Python передаёт маску в выбранную ноду.

Также можно выбрать общий пункт для всех нод, отмеченных `#PS-MASK`.

Автоматический выбор выполняется в следующем порядке:

1. ноды с `#PS-MASK`;
2. подключённый выход `MASK` основного `Load Image`;
3. единственная подходящая `Load Image Mask`;
4. маска не задана.

При обычной img2img-генерации отсутствие маски не является ошибкой. При Quick Mask inpainting запуск останавливается, если выбранный источник маски не подключён корректно.

Quick Mask inpainting относится к режиму ComfyUI. Готовые Forge-схемы работают с обычным изображением выделенной области.

## Forge Neo и JSON-схемы

Forge Neo использует независимые JSON-схемы. Каждая схема описывает:

- название и порядок preset;
- элементы интерфейса;
- значения по умолчанию;
- источники выпадающих списков;
- поля API payload;
- endpoint генерации;
- возможности вроде ImageStitch;
- условия включения отдельных параметров.

Поставляемые схемы не используют `base.json` или `extends`: каждый файл является самостоятельным.

### Поиск папки схем

Если путь не сохранён, скрипт проверяет:

1. `forge-schemas` рядом с JSX;
2. `lib\forge-schemas` рядом с JSX;
3. папку JSX;
4. папку `lib` рядом с JSX.

Путь можно выбрать вручную в общих настройках.

### Поставляемые presets

| Preset | Начальные параметры | Особенности |
|---|---|---|
| `SD` | Euler a, Automatic, 32 steps, CFG 6 | Обычный Forge img2img |
| `SDXL` | Euler a, Automatic, 24 steps, CFG 4.5 | Обычный Forge img2img |
| `FLUX` | Euler, Beta, 20 steps, CFG 1, Distilled CFG 3 | ImageStitch до 3 файлов |
| `KLEIN` | Euler, Beta, 4 steps, CFG 1 | ImageStitch до 3 файлов |
| `QWEN` | LCM, Normal, 8 steps, CFG 1 | ImageStitch до 3 файлов |
| `Lumina` | Res Multistep, Simple, 32 steps, CFG 4, Shift 6 | Дополнительный параметр Shift |
| `Anima` | ER SDE, Beta, 32 steps, CFG 4, Shift 3 | Дополнительный параметр Shift |
| `Ernie` | Euler, Simple, 8 steps, CFG 1, Shift 3 | Дополнительный параметр Shift |
| `KREA` | Euler, Simple, 8 steps, CFG 1 | Обычный Forge img2img |
| `Z-Image` | Euler, Beta, 9 steps, CFG 1, Shift 9 | Дополнительный параметр Shift |
| `Face Restore` | GFPGAN и CodeFormer | Endpoint `extra-single-image` |
| `Upscaler` | Resize 4× | Endpoint `extra-single-image` |

Это стартовые значения JSON-схем. Сохранённые значения каждого Forge profile хранятся отдельно и не перезаписываются при обычном запуске.

### Видимость параметров

В редакторе схемы можно выбрать поля главного окна.

Поля `Checkpoint` и `VAE / Text encoders` в генерационных схемах имеют `required_visible` и не скрываются.

Если параметр скрыт, при генерации используется `value` из JSON-схемы, а не ранее сохранённое пользовательское значение.

`Seed` во всех поставляемых генерационных Forge-схемах изначально скрыт и имеет значение `-1`.

### Создание собственной схемы

Проще всего скопировать ближайший по назначению JSON-файл и изменить:

```json
{
  "kind": "photoshop-helper-forge-schema",
  "backend": "forge",
  "schema_version": 1,
  "id": "my-schema",
  "label": "My Schema",
  "order": 200,
  "controls": []
}
```

Наиболее важные разделы:

- `id` — уникальный идентификатор профиля;
- `label` — название в списке `UI Preset`;
- `order` — порядок сортировки;
- `controls` — элементы интерфейса;
- `generation` — endpoint и правила формирования запроса;
- `fixed_values` — постоянные поля payload;
- `capabilities` — дополнительные возможности.

Поддерживаемые типы контролов зависят от общей схемы интерфейса и включают строки, многострочные поля, числа, флаги, dropdown и multiselect.

После добавления нового файла нажмите `⟳` рядом со списком Forge preset.

## Face Restore

Схема `face-restore.json` отправляет выделенную область в:

```text
sdapi/v1/extra-single-image
```

Поддерживаются:

- GFPGAN;
- CodeFormer.

Для каждого метода можно изменить степень смешивания результата. Для CodeFormer дополнительно доступен `CodeFormer weight`:

- `0` — максимальный эффект;
- `1` — минимальный эффект.

Связанные параметры отключаются в интерфейсе, если выключен соответствующий метод.

Необходимо включить хотя бы GFPGAN или CodeFormer. Если оба выключены, кнопка `Generate` блокируется.

Face Restore не переключает checkpoint и дополнительные модули Forge.

## Upscaler

Схема `upscaler.json` использует тот же endpoint:

```text
sdapi/v1/extra-single-image
```

Доступны:

- `Resize` — коэффициент увеличения от `0` до `8` с шагом `0.25`;
- `Upscaler 1`;
- `Upscaler 2`;
- `Upscaler 2 visibility` — смешивание второго upscaler;
- `Color Correction`.

Начальный коэффициент — `4`.

Список upscaler загружается из Forge Neo через:

```text
/sdapi/v1/upscalers
```

Если Forge возвращает пустой список, соответствующие dropdown блокируются.

## ImageStitch

ImageStitch включён в поставляемых схемах:

- FLUX;
- KLEIN;
- QWEN.

Поведение:

- выделение Photoshop передаётся как основное изображение img2img;
- в ImageStitch передаются только выбранные файлы-референсы;
- можно выбрать до трёх файлов;
- если не выбран ни один файл, ImageStitch не активируется и ошибка не показывается;
- выключенный блок не занимает место отдельными списками файлов.

ComfyUI и Forge используют общую историю последних десяти reference-файлов. Дубликаты и отсутствующие файлы удаляются автоматически.

## Интерфейс

### Верхняя строка

- размер текущей области обработки;
- `LOAD` — загрузить параметры из метаданных активного сгенерированного слоя;
- `⚙` — открыть общие настройки.

Кнопка `LOAD` показывается только при наличии совместимых метаданных.

### Backend

Список появляется, когда одновременно доступны ComfyUI и Forge Neo.

### ComfyUI Workflow

- список `Workflow` — выбор API JSON;
- `↻` — обновить список файлов;
- `⟳` — повторно проанализировать выбранный workflow;
- `⚙` — открыть привязки и видимость параметров.

### Forge UI Preset

- список `UI Preset` — выбор JSON-схемы;
- `↻` — обновить данные текущей схемы и связанные каталоги Forge;
- `⟳` — перечитать список схем и обновить текущую;
- `⚙` — выбрать параметры главного окна.

### Динамические параметры

В зависимости от workflow или Forge schema могут отображаться:

- Checkpoint;
- VAE и text encoders;
- LoRA;
- Prompt и Negative prompt;
- Sampling method;
- Schedule type;
- Sampling steps;
- CFG Scale;
- Distilled CFG Scale;
- Shift;
- Guidance;
- Denoising strength;
- Seed;
- параметры custom nodes;
- изображения-референсы;
- ImageStitch;
- Resize.

### Числовые поля

Для ComfyUI типы, диапазоны и шаги берутся из `/object_info`.

Основные правила интерфейса:

- `INT` сохраняется как целое число;
- `FLOAT` сохраняется как дробное число;
- `Denoising strength` обычно использует диапазон `0.00–1.00` и шаг `0.01`;
- CFG-подобные поля с крупным шагом используют шаг `0.5`;
- `Sampling steps` в главном интерфейсе ограничен значением `100`;
- поля с отсутствующим или слишком широким диапазоном могут отображаться как текстовый ввод вместо slider.

Если Seed показан, кнопка `↻` создаёт случайное значение. После отправки видимого Seed скрипт подготавливает новое случайное значение для следующего запуска.

## Промпты, пресеты, перевод и LoRA

### Prompt и Negative prompt

Оба поля поддерживают библиотеку текстовых пресетов.

Панель содержит:

- `↻` — восстановить текст выбранного пресета;
- `+` — добавить новый пресет;
- `✔` — сохранить изменения в выбранный пресет;
- `×` — удалить пресет.

Пресет `по умолчанию` нельзя удалить или перезаписать.

Кнопки сохранения и восстановления блокируются, когда текст не отличается от выбранного пресета.

В Negative prompt изначально доступны встроенные пресеты:

- `SD`;
- `Realistic`.

Библиотеки Prompt и Negative prompt являются общими для ComfyUI, Forge Neo и Photoshop Actions. Текущий текст при этом сохраняется отдельно для конкретного workflow, Forge preset или записанного Action.

### Перевод

Кнопка перевода переводит текущий промпт на английский.

При первом использовании Python API:

1. проверяет наличие `deep_translator`;
2. при необходимости запускает `pip`;
3. при отсутствии `pip` пытается использовать `ensurepip`;
4. устанавливает пакет `deep-translator`;
5. при недостатке прав повторяет установку с `--user`;
6. выполняет перевод без перезапуска Photoshop.

Первая установка может занять несколько минут. Подробности записываются в `img2img-api.log`.

### LoRA в ComfyUI

Анализатор добавляет найденные строковые поля выбора LoRA в рекомендуемый набор параметров. Поддерживается несколько LoRA-нод в одном workflow.

Найденные LoRA dropdown располагаются сразу после Positive prompt.

### LoRA в Forge Neo

Рядом с Positive prompt доступна кнопка `+ LoRA`, если Forge вернул хотя бы одну запись из:

```text
/sdapi/v1/loras
```

Кнопка открывает окно поиска и вставляет выбранную LoRA в формате:

```text
<lora:name:1>
```

При загрузке положительного текстового пресета уже находящиеся в поле теги `<lora:...>` сохраняются. При сохранении положительного пресета LoRA-теги из текста удаляются, поэтому библиотека хранит только обычный текст промпта.

## Resize и кратность размеров

### Auto resize

`Auto resize` рассчитывает масштаб по:

- размеру выделения;
- минимальной стороне выбранного профиля;
- максимальному числу мегапикселей.

Встроенные профили:

| Профиль | Минимальная сторона | Максимальная площадь |
|---|---:|---:|
| `SD` | 512 px | 1.5 MP |
| `SDXL` | 640 px | 2 MP |
| `FLUX/QWEN` | 512 px | 2 MP |
| `HiRes` | 1024 px | 4 MP |

Профили `SD`, `SDXL` и `FLUX/QWEN` защищены от удаления. Пользовательские профили можно создавать, обновлять и удалять в общих настройках.

Максимальный автоматический масштаб ограничен значением `4×`.

### Ручной масштаб

При выключенном `Auto resize` используется сохранённое положение slider. Ручное изменение slider временно переводит текущий профиль на выбранный масштаб.

### Кратность

Каждый ComfyUI workflow и Forge preset хранит собственную кратность `width/height`. Начальное значение — `16`.

Перед генерацией границы выделения уменьшаются до ближайшего меньшего размера, кратного этому значению. Уменьшение выполняется симметрично относительно центра области, насколько позволяют границы документа.

Например, при кратности `16` область `1013 × 767` станет:

```text
1008 × 752
```

Скрипт не увеличивает выделение за его исходные границы. Это помогает избежать светлых ореолов и несовпадения маски при обратном размещении результата.

Проверка выполняется при показе интерфейса и повторно непосредственно перед генерацией, включая тихий режим.

## Размещение результата в Photoshop

После генерации файл помещается в документ командой Place.

Доступны два режима:

### Точное растяжение

По умолчанию результат масштабируется независимо по ширине и высоте и точно заполняет границы выделения.

### Сохранение пропорций

При включённой настройке `Сохранять пропорции при размещении` используется единый коэффициент масштаба. Изображение вписывается в границы выделения без искажения пропорций.

Дополнительные настройки:

- `Растеризовать сгенерированное изображение` — превратить размещённый smart object в обычный слой;
- `Активировать кисть после генерации` — выбрать маску нового слоя и инструмент Brush;
- `Непрозрачность кисти` — установить opacity кисти;
- `Сохранять настройки в метаданных слоя` — записать параметры генерации в XMP.

Результирующий слой получает имя:

```text
generated image
```

## Настройки workflow и схемы Forge

### ComfyUI workflow

Для каждого workflow отдельно сохраняются:

- основной вход Photoshop;
- вход inpaint-маски;
- выбранные reference-входы;
- выходная нода;
- нода размера;
- параметры главного окна;
- кратность размеров;
- значения контролов;
- выбранные reference-файлы;
- resize profile и ручной масштаб;
- кеш анализа.

Кнопки `Рекомендуемые`, `Выбрать все` и `Снять все` управляют видимостью параметров.

Если workflow не содержит обязательного входа или выхода, `Generate` отключается и показывается диагностическое сообщение.

### Forge schema

Для каждого Forge preset отдельно сохраняются:

- значения контролов;
- видимые поля;
- ImageStitch inputs;
- кратность размеров;
- resize profile;
- ручной масштаб.

Checkpoint и `VAE / Text encoders` нельзя скрыть в поставляемых генерационных схемах.

## Настройки скрипта

Общие настройки открываются кнопкой `⚙` в верхней строке.

### Подключение

- `IP / host` — адрес компьютера с ComfyUI или Forge Neo;
- `ComfyUI port` — по умолчанию `8188`;
- `Forge Neo port` — по умолчанию `7860`;
- `API workflow folder` — папка с ComfyUI API JSON;
- `Forge schema folder` — папка с JSON-схемами Forge;
- `↻` — повторно найти запущенные бэкенды.

Поля неактивного режима блокируются: в ComfyUI недоступны Forge port и папка схем, а в Forge недоступны ComfyUI port и папка workflow.

### Профили автомасштаба

Можно:

- восстановить значения выбранного профиля;
- добавить профиль;
- сохранить изменения;
- удалить пользовательский профиль.

Для профиля задаются:

- минимальная сторона;
- максимальное количество мегапикселей.

### Параметры изображения

- `Объединять слои перед генерацией`;
- `Растеризовать сгенерированное изображение`;
- `Сохранять пропорции при размещении`.

### Кисть

- `Активировать кисть после генерации`;
- `Непрозрачность кисти`.

### Actions и метаданные

- `Записывать настройки в экшен`;
- `Сохранять настройки в метаданных слоя`;
- `Таймаут генерации, с`.

Начальный таймаут генерации — `1200` секунд. Допустимый диапазон в настройках — от `30` до `86400` секунд.

## Режимы запуска

### Диалоговый режим

Перед генерацией открывается главное окно.

Диалоговый режим используется:

- при первом запуске;
- после ошибки;
- после отмены;
- после закрытия окна через `Esc`;
- при запуске с зажатой клавишей `Shift`;
- при включённом значке диалога у шага в Photoshop Actions.

Закрытие главного окна через `Esc` сохраняет текущие параметры и заставляет следующий запуск снова открыть интерфейс.

### Тихий режим

Главное окно не открывается. Скрипт использует сохранённый backend, workflow или Forge preset и последние параметры.

После успешного запуска из диалогового режима последующие обычные запуски выполняются в тихом режиме.

Перед тихой генерацией скрипт повторно проверяет кратность области и корректность сохранённых значений списков.

## Photoshop Actions

### Записывать настройки в экшен включено

Action хранит собственные значения генерации. Один и тот же `img2img helper` можно записать в несколько Actions с разными workflow, Forge presets и параметрами.

### Записывать настройки в экшен выключено

Action запускает скрипт, но использует текущие общие настройки из файла:

```text
img2img helper.desc
```

### Общие библиотеки

Пресеты Prompt, Negative prompt и история reference-файлов остаются общими между обычным запуском и Actions. Изменения библиотек во время воспроизведения Action сохраняются в обычный файл настроек.

### Диалог при воспроизведении

Включите значок диалога рядом с шагом `img2img helper` в палитре Actions, чтобы при воспроизведении открыть главное окно.

Если значок выключен, Action работает в тихом режиме.

Явная отмена генерации возвращает Photoshop состояние `cancel`. Обычная ошибка после успешной загрузки настроек сохраняет текущие параметры и позволяет Action продолжить следующие шаги.

## Метаданные слоя

При включённой настройке `Сохранять настройки в метаданных слоя` скрипт записывает параметры генерации в XMP нового слоя.

Метаданные могут содержать:

- активный backend;
- workflow или Forge preset;
- значения параметров;
- resize settings;
- привязки и reference-файлы, относящиеся к профилю.

Если активный слой содержит совместимые метаданные, в верхней строке появляется кнопка `LOAD`.

Нажатие `LOAD`:

1. переключает backend;
2. выбирает нужный workflow или Forge preset;
3. восстанавливает сохранённые параметры;
4. перестраивает главное окно.

Если соответствующий workflow, preset или файл больше не существует, загрузка не выполняется.

## Работа по сети

ComfyUI и Forge Neo могут работать на другом компьютере в локальной сети.

1. Разрешите выбранной оболочке принимать подключения не только с `127.0.0.1`.
2. Откройте её порт в брандмауэре удалённого компьютера.
3. В настройках `img2img helper` укажите IP-адрес или имя компьютера.
4. Укажите отдельные порты ComfyUI и Forge Neo.

Локальный транспорт между Photoshop и `img2img-api.pyw` всегда работает только на компьютере с Photoshop:

```text
127.0.0.1:6370 — команды JSX → Python
127.0.0.1:6371 — ответы Python → JSX
```

Настройка `IP / host` изменяет адрес ComfyUI и Forge Neo, но не адрес локального Python API.

Встроенное соединение с бэкендами использует обычный HTTP без HTTPS и авторизации. Не публикуйте порты ComfyUI или Forge Neo напрямую в интернет.

## Progress bar и отмена

Генерация разделена на два сегмента встроенного progress bar Photoshop.

### 1. Инициализация модели — 30%

В этот этап входят:

- подготовка backend;
- переключение checkpoint и дополнительных модулей Forge;
- загрузка входного изображения в ComfyUI;
- изменение копии workflow;
- постановка задачи в очередь;
- ожидание фактического начала обработки.

### 2. Генерация изображения — 70%

Сегмент начинается после того, как Python подтвердил начало выполнения или завершение очень быстрой задачи. В заголовке показывается прошедшее время.

Для Forge обычный img2img progress читается через `/sdapi/v1/progress`. Для Face Restore и Upscaler, которые не публикуют sampling progress, второй этап начинается после отправки запроса.

При отмене Photoshop передаёт Python команду прерывания. Для ComfyUI выполняется удаление queued prompt или interrupt; для Forge запрос помечается отменённым, насколько это допускает работающий endpoint.

## Кеш, временные файлы и журнал

### Настройки Photoshop

Основные настройки сохраняются в:

```text
img2img helper.desc
```

Файл находится в каталоге настроек текущей версии Photoshop.

Для полного сброса:

1. закройте Photoshop;
2. удалите `img2img helper.desc` из папки настроек Photoshop;
3. запустите Photoshop снова.

### Рабочий каталог Python

```text
%LOCALAPPDATA%\img2img helper\
```

Основные элементы:

```text
cache\
state\
temp\
img2img-api.log
```

Python API автоматически завершается примерно после десяти минут бездействия и при следующем запуске скрипта стартует снова.

### Журнал

```text
%LOCALAPPDATA%\img2img helper\img2img-api.log
```

Проверяйте его при:

- ошибке запуска Python;
- ошибке соединения;
- timeout;
- ошибке ComfyUI workflow;
- ошибке Forge API;
- проблеме перевода;
- ошибке установки `deep-translator`;
- неожиданном завершении Python API.

Журнал имеет ограниченный размер и автоматически ротируется.

### Кеш ComfyUI workflow

Анализ workflow кешируется. Кеш перестаёт использоваться после изменения размера или времени модификации JSON, изменения версии кеша или правил анализатора.

Для ручного обновления выбранного workflow нажмите `⟳`.

Для полного сброса Python-кеша удалите:

```text
%LOCALAPPDATA%\img2img helper\cache\
```

Часть схемы также хранится в профиле Photoshop и обновляется кнопкой `⟳`.

### Входные изображения ComfyUI

Загруженные файлы помещаются в:

```text
ComfyUI\input\img2img-helper\
```

Если ComfyUI работает локально и Python смог определить папку `input`, собственные загруженные изображения удаляются после завершения, ошибки или отмены.

Папка `img2img-helper` и чужие файлы не удаляются.

При удалённом ComfyUI автоматическая очистка его файловой системы невозможна. Периодически очищайте эту папку вручную.

Файлы, которые workflow создаёт в `ComfyUI\output`, скрипт не удаляет.

### Временные файлы Photoshop

JSX использует временную папку:

```text
%TEMP%\img2img helper\
```

В ней кратковременно создаются JPEG, PNG-маски и полученные изображения. Скрипт пытается удалить файлы после завершения операции.

## Типичные проблемы

### Не найден ComfyUI или Forge Neo

- Убедитесь, что хотя бы одна оболочка запущена.
- Проверьте `IP / host`.
- Проверьте порты `8188` и `7860` либо ваши пользовательские значения.
- Нажмите `↻` в общих настройках для полного повторного поиска.
- Для удалённого компьютера проверьте брандмауэр и параметры запуска сервера.

### Python API не запускается

- Убедитесь, что Python установлен.
- Запустите `img2img-api.pyw` двойным щелчком.
- Проверьте системную ассоциацию `.pyw`.
- Убедитесь, что JSX и Python-файл находятся рядом либо используется подпапка `lib`.
- Проверьте журнал `%LOCALAPPDATA%\img2img helper\img2img-api.log`.

### После замены Python-файла работает старая версия

Запущенный `pythonw.exe` не перечитывает файл после замены. Python API также может оставаться активным до десяти минут после последнего обращения.

Найдите процесс, слушающий порт `6370`:

```bat
netstat -ano | findstr :6370
```

Завершите его:

```bat
taskkill /PID НОМЕР_PID /F
```

После этого запустите скрипт снова.

JSX и Python API используют общий protocol version, поэтому обновляйте `img2img helper.jsx` и `img2img-api.pyw` вместе.

### Папка workflow не выбрана

В режиме ComfyUI главное окно блокируется, кроме кнопки общих настроек.

Нажмите `⚙` и выберите папку с файлами `Export Workflow (API)`.

### Папка Forge schemas не найдена

- Убедитесь, что папка `forge-schemas` скопирована вместе со скриптом.
- Откройте общие настройки и выберите её вручную.
- Проверьте, что JSON содержит правильные `kind`, `backend` и `schema_version`.

### Workflow не прошёл проверку

- Проверьте основной вход и выход.
- Добавьте `#PS-INPUT` и `#PS-OUTPUT`.
- Повторно экспортируйте API JSON.
- Нажмите `⟳`.
- Для inpainting проверьте подключение MASK.

### Параметры workflow устарели

- Нажмите `⟳` рядом с workflow.
- При необходимости удалите `%LOCALAPPDATA%\img2img helper\cache\`.
- Повторно экспортируйте workflow после изменения заголовков нод.

### В Forge нет моделей, sampler, LoRA или upscaler

- Дождитесь полной загрузки Forge Neo.
- Проверьте соответствующие API endpoints.
- Нажмите `↻` рядом с текущей схемой.
- Для полного обновления статуса и очистки каталога Python нажмите `↻` в общих настройках.

### Generate отключена в Face Restore

Включите GFPGAN, CodeFormer или оба метода.

### ImageStitch не работает

- Используйте FLUX, KLEIN или QWEN preset.
- Включите `ImageStitch inputs`.
- Выберите хотя бы один существующий файл.
- Проверьте наличие ImageStitch Integrated в Forge Neo.

### Translate не работает

- Проверьте доступ в интернет.
- Дождитесь завершения первой установки `deep-translator`.
- Проверьте `img2img-api.log`.
- Убедитесь, что `pip` не блокируется антивирусом, прокси или политиками организации.

### Результат имеет неправильные пропорции

- Для точного заполнения области выключите `Сохранять пропорции при размещении`.
- Для сохранения исходных пропорций результата включите эту настройку.
- Проверьте размер, который показывает блок Resize.

### Размер области немного уменьшился

Это штатное поведение. Скрипт уменьшает выделение до ближайшей меньшей кратности, заданной для workflow или Forge preset.

### Ошибка содержит слишком много текста

Короткие сообщения показываются стандартным `alert`. Для длинных ошибок открывается отдельное окно с прокручиваемым полем `Подробности ошибки`.

## Ограничения

- Поддерживается только Windows.
- Документ Photoshop должен быть в режиме RGB.
- ComfyUI принимает только workflow, экспортированные в API format.
- Готовые Forge-схемы рассчитаны на Forge Neo; совместимость с Automatic1111 и старыми сборками Forge не гарантируется.
- В Photoshop вставляется только первое изображение результата.
- Quick Mask inpainting требует корректного ComfyUI mask binding.
- Автоматическая очистка загруженных изображений недоступна для удалённого ComfyUI.
